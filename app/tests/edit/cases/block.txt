Block commands (docs/EDIT-MODE.md §8.4-§8.7): paragraph and heading styles, lists, quotes, code blocks - per text block
the caret or the selection touches, and in a phantom row its style (§6.7). src holds the caret ‸ or a selection ⟦ … ⟧;
want the source afterwards; phantom where a phantom row stands then. Each case also runs with CRLF line ends, inside a
quote and inside a list item unless its flags say otherwise.

=== h2_lines_join (§8.4's example: `line one⏎line two` + Ctrl+2 → `## line one line two`)
src: ‸line one\nline two\n
do: H2
want: ## ‸line one line two\n

=== h2_hard_break (§8.4: a hard break becomes <br>)
src: one\\\ntw‸o\n
do: H2
want: ## one<br>tw‸o\n

=== h2_twice_text (§8.4: Ctrl+n on a heading of level n returns it to a paragraph)
src: ## ti‸tle\n
do: H2
want: ti‸tle\n

=== h1_from_h3 (§8.4: ATX m → n changes the # run only; the closing sequence stays)
src: ### ti‸tle ###\n
do: H1
want: # ti‸tle ###\n

=== h2_from_setext (§8.4: setext → ATX, the underline gone)
src: Ti‸tle\n===\n
do: H2
want: ## Ti‸tle\n

=== p_from_setext
src: Ti‸tle\n---\n
do: P
want: Ti‸tle\n

=== p_escapes (§8.4's example: `# 1. Intro` → `1\. Intro`)
src: # ‸1. Intro\n
do: P
want: ‸1\\. Intro\n

=== p_closing_sequence (the closing sequence goes too)
src: ## ti‸tle ##\n
do: P
want: ti‸tle\n

=== h2_alert_one_line (§8.4, F24: a one-line alert's tag goes onto its own line first)
src: > [!NOTE] Remember‸ this\n
flags: noquote nolist
do: H2
want: > [!NOTE]\n> ## Remember‸ this\n

=== h2_in_item (§8.4: `- ## x` is valid)
src: - it‸em\n
flags: nolist
do: H2
want: - ## it‸em\n

=== h1_selection_blocks (§8.1: every text block the selection touches)
src: ⟦a\n\nb⟧\n
flags: nolist
do: H1
want: # ⟦a\n\n# b⟧\n

=== h1_skips_code (a code block in the selection keeps its lines)
src: ⟦a\n\n```\nx\n```\n\nb⟧\n
flags: nolist
do: H1
want: # ⟦a\n\n```\nx\n```\n\n# b⟧\n

=== p_empty_heading_phantom (§6.7: an empty heading made a paragraph: a phantom row in its place)
src: abc\n\n##‸\n\ndef\n
flags: nolist
do: H2
want: abc‸\n\ndef\n
phantom: after 0 in

=== style_phantom (§6.7, §8.1: in a phantom the command sets its style; typing writes it)
src: abc‸\n
flags: nolist
do: Enter; H3; type "x"
want: abc\n\n### x‸\n

=== style_phantom_state
src: abc‸\n
flags: nolist
do: Enter; H3
want: abc‸\n
phantom: after 0 in style 3

=== style_in_cell_refused (§8.1: no block style in a table)
src: | a‸ |\n| --- |\n
do: H1
want: | a‸ |\n| --- |\n
state: refused=context
