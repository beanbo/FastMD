The operations of Phase 2a (docs/EDIT-MODE.md §6.3, §6.5, §6.6, §7.3, §7.7 in a block, §7.9 in a block, §8.10): typing
at a caret, Backspace and Delete inside a block, a selection inside one block, a task box. src holds the caret ‸ (or a
selection ⟦ … ⟧, anchor first); `do` lists the operations; want is the source after them, with the caret where the glue
puts it (normalised: where typed text would go next). Each case also runs with CRLF line ends, inside a quote and inside a
list item. Phase 2b's structure (Enter, joins across blocks, selections across blocks, escaping) is in the other files.

=== type_bold_end (§6.3 **bold‸** tail: typing continues the bold)
src: **bold‸** tail\n
do: type "x"
want: **boldx‸** tail\n

=== type_before_bold (§6.3 plain ‸**bold**)
