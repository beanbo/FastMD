The operations of Phase 2a (docs/EDIT-MODE.md §6.3, §6.5, §6.6, §7.3, §7.7 in a block, §7.9 in a block, §8.10): typing
at a caret, Backspace and Delete inside a block, a selection inside one block, a task box. src holds the caret ‸ (or a
selection ⟦ … ⟧, anchor first); `do` lists the operations; want is the source after them, with the caret where the glue
puts it (normalised: where typed text would go next). Each case also runs with CRLF line ends, inside a quote and inside a
list item. Phase 2b adds the structure (Enter, joins across blocks, selections across blocks, escaping).

=== type_bold_end (§6.3 **bold‸** tail: typing continues the bold)
src: **bold‸** tail\n
do: type "x"
want: **boldx‸** tail\n

=== type_before_bold (§6.3 plain ‸**bold**)
src: plain ‸**bold**\n
do: type "x"
want: plain x‸**bold**\n

=== type_block_start_bold (§6.3 ‸**Bold** at the block start: inside the enterable opener)
src: ‸**Bold** text\n
do: type "x"
want: **x‸Bold** text\n

=== type_before_link (§6.3 see ‸[Docs](u))
src: see ‸[Docs](u)\n

want: see x‸[Docs](u)\n

=== type_link_end (§6.3 [Docs‸](u) more: never inside a link from its right edge)
src: [Docs‸](u) more\n
do: type "x"
want: [Docs](u)x‸ more\n

=== type_block_start_link (§6.3 ‸[Docs](u) at the block start: outside the link)
src: ‸[Docs](u) are\n
do: type "x"
want: x‸[Docs](u) are\n

=== type_before_code (§6.3 run ‸`make`)
