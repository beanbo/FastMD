# FastMD — мгновенный просмотр Markdown для Windows

**~64 мс** от запуска до отрисованного документа (medium.md, 53 КБ). Это быстрее пустого Win32-окна без оптимизаций (≈80 мс).
Для сравнения: Void открывает окно за 1,4 с, VS Code за 1,1 с, Typora за 1,7 с (подробности в [../REPORT.md](../REPORT.md)).

Стек: **C++20, Win32, DirectWrite, md4c**.
- Первый кадр рисуется на CPU (DirectWrite → GDI DIB), без GPU-устройства.
- Сначала верстается только первый экран.
- Всё остальное после первого кадра делается в фоновых потоках.
- Один маленький exe (≈0,6 МБ), статический CRT, никаких рантаймов.

## Сборка

Нужна Visual Studio 2022 или новее (любая редакция или Build Tools) с workload «Desktop development with C++»: MSVC, Windows SDK, CMake и Ninja входят в неё. `tools/msvc.cmd` находит установку через vswhere.

```
pwsh -File app/build.ps1            # dev-сборка → app/build/Release/FastMD.exe (тесты, замеры)
pwsh -File app/build.ps1 -Config Debug
pwsh -File app/publish.ps1          # обновить рабочую копию app/out/Release/FastMD.exe (на неё указывает ассоциация .md)
```

## Использование

```
FastMD.exe файл.md
```

- **Ассоциация с `.md`.** Выберите пункт контекстного меню «Открывать .md в FastMD…» или выполните `FastMD.exe --register`. Программа регистрируется в HKCU, права администратора не нужны, и откроются «Параметры → Приложения по умолчанию → FastMD». Назначить приложение программно Windows не даёт, поэтому подтверждаете вы. Отменить регистрацию: `FastMD.exe --unregister`.
- **Настройки** (тема, масштаб, положение, размер и развёрнутость окна) хранятся в `HKCU\Software\FastMD`. Окно открывается там, где было закрыто последнее; несколько документов, открытых подряд, раскладываются каскадом.
- `publish.ps1` можно запускать при открытых документах: работающий exe переименовывается (`FastMD.old-*.exe`, удаляется при следующей публикации), новые окна запускают новую версию.

### Клавиши и мышь

| Действие | Клавиши |
|---|---|
| Прокрутка | колесо, ↑ ↓, PgUp / PgDn, Пробел / Shift+Пробел, Home / End |
| Выделение | мышь; двойной клик выделяет слово, тройной — абзац или ячейку; Shift+клик расширяет выделение |
| Копировать / выделить всё | Ctrl+C / Ctrl+A |
| Копировать блок кода | кнопка в правом верхнем углу блока (появляется при наведении) |
| Поиск | Ctrl+F; Enter / F3 — следующее совпадение, Shift+Enter / Shift+F3 — предыдущее, Esc — закрыть |
| Масштаб | Ctrl+колесо, Ctrl + / Ctrl −, Ctrl+0 |
| Ссылки | клик: `#якорь` прокручивает к заголовку, `.md` открывается здесь же, `http(s)` и `mailto` — в браузере, прочее — после подтверждения |
| Назад / вперёд | Alt+← / Alt+→, Backspace, боковые кнопки мыши |
| Открыть / обновить | Ctrl+O, перетаскивание файла в окно / F5 или Ctrl+R (при изменении на диске обновляется само) |
| Открыть в редакторе | Ctrl+E |
| Закрыть | Esc (если нет выделения), Ctrl+W |
| Меню | правый клик: тема (системная / светлая / тёмная), масштаб, «Показать в папке», ассоциация |

## Что поддерживается

- **Разметка:**
  - CommonMark + GFM: таблицы с выравниванием, списки задач, зачёркивание, автоссылки;
  - заголовки с якорями по правилам GitHub;
  - вложенные списки и цитаты;
  - GitHub Alerts `> [!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]`;
  - YAML front matter (показывается блоком YAML).
- **Код:** подсветка синтаксиса для c/cpp/cs/js/ts/rust/python/powershell/json/go/java/bash/sql/css/xml/yaml/toml. Широкие блоки кода и таблицы выходят за колонку текста (680 DIP) до 960 DIP.
- **Картинки и шрифты:**
  - локальные картинки (PNG/JPEG/GIF/BMP/WebP через WIC, место резервируется заранее);
  - цветные эмодзи, CJK, кириллица.
- **Оформление:**
  - светлая и тёмная темы GitHub, по системе или вручную, без белой вспышки при запуске;
  - тёмный заголовок и Mica в заголовке окна.
- **Большие файлы:** документ 3,7 МБ показывает первый экран за те же ~65 мс. Для него разбирается только начало файла, остальное дочитывается в фоне.

## Известные ограничения v0.1

- Нет горизонтальной прокрутки широких блоков кода и таблиц: всё, что не влезло, обрезается.
- Сырой HTML: теги вырезаются, текст остаётся, `<br>` работает. HTML-подмножество в планах.
- Удалённые картинки и SVG не загружаются: вместо них заглушка с alt-текстом.
- Нет сносок (нужен md4c master), оглавления, печати и доступности для экранных дикторов (UIA).
- Строка поиска принимает текст в любой раскладке, но без IME-композиции для CJK: IME отключён для UI-потока ради скорости старта.

Подробный план всех оставшихся шагов — [../docs/PLAN.md](../docs/PLAN.md), история изменений — [../CHANGELOG.md](../CHANGELOG.md).

## Устройство

| Модуль | Что делает |
|---|---|
| `src/window.cpp` | окно, ввод, команды, меню, настройки, ассоциация, `wWinMain` |
| `src/loader.cpp` | загрузка документа (стартовый поток параллельно с созданием окна; открытие, перезагрузка, история), фоновые замеры высот, WIC, наблюдение за файлом |
| `src/view.cpp` | колонки и вынос широких блоков, виртуализированная вёрстка, отрисовка, hit-testing, выделение, поиск, оверлеи |
| `src/parse.cpp` | md4c → плоская модель блоков; alerts, front matter, slug-и заголовков |
| `src/layout.cpp` | типографика (Segoe UI Variable Text/Display, Cascadia Mono) и вёрстка блоков |
| `src/canvas_gdi.cpp` | CPU-рендер: DirectWrite → DIB, SDF-растеризатор фигур, послойные COLR-эмодзи |
| `src/theme.cpp` | палитры GitHub light/dark |
| `src/util.cpp` | хуки бенч-протокола, трассировка (`FASTMD_TRACE=1` → `%TEMP%\fastmd-trace.txt`), файлы |

Модель документа — один UTF-16 буфер текста. У каждого блока и ячейки таблицы свой диапазон в этом буфере. Поэтому позиция в тексте — это одно число, а выделение и поиск работают единообразно через блоки и ячейки.

## Тесты

- **Скорость** проверяется тем же харнессом, что и при выборе стека. Вариант `fastmd-app` зарегистрирован в `bench/protos/fastmd-app`:
  ```
  python bench/harness/bench.py run fastmd-app,baseline-win32 --doc small,medium,large --runs 12
  ```
  Правило: FastMD не медленнее `baseline-win32` на medium и не больше чем на +15 мс на large.
- **UI-смоук** запускает настоящее окно и проверяет выделение, копирование, поиск, ссылки, зум, тему, историю и живую перезагрузку. Скриншоты сохраняются в `app/tests/out/`.
  ```
  python app/tests/ui_smoke.py
  ```
