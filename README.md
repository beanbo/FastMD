# FastMD

**Молниеносный просмотрщик Markdown для Windows.** От запуска до отрисованного документа проходит около 65 мс. Пустое окно Win32 без настройки открывается дольше.

*Lightning-fast Markdown reader for Windows (C++20, Win32, DirectWrite, md4c): the first screen of a document is on the display ~65 ms after process start. Documentation is in Russian.*

![FastMD, светлая тема](bench/results/shots/fastmd-app-medium.png)

## Почему так быстро

Стек выбран по замерам: 12 прототипов, 47 вариантов, один харнесс и один протокол. Подробности — в [REPORT.md](REPORT.md). Ниже время от запуска процесса до отрисованного документа (medium.md, 53 КБ, медиана):

| Что открываем | мс |
|---|---|
| **Прототип FastMD: C++, Win32, DirectWrite, первый кадр на CPU** | **59** |
| Пустое окно Win32 без настройки | 78 |
| Qt 6 Widgets | 149 |
| WinUI 3 (C#, NativeAOT) | 324 |
| WebView2 / Tauri | 447–630 |
| Electron (класс Typora, Obsidian) | 753–903 |
| VS Code, только окно | 1 138 |

Сам FastMD 0.1.1 в контрольном прогоне: 66 мс против 87 мс у пустого окна в тех же условиях.

Главные приёмы:

- первый кадр рисуется на CPU (DirectWrite → GDI DIB), ведь GPU-устройство до первого кадра стоило бы +150–250 мс;
- сначала верстается только первый экран, остальное делается в фоне после первого кадра;
- один маленький exe (~0,6 МБ), статический CRT, никаких рантаймов;
- при первом показе окна отключены инициализация IME в UI-потоке и анимация открытия.

## Возможности

- CommonMark и GFM: таблицы, списки задач, зачёркивание, автоссылки. GitHub Alerts, YAML front matter.
- Подсветка кода для 17 языков, цветные эмодзи, CJK, локальные картинки.
- Выделение и копирование, поиск (Ctrl+F), масштаб, светлая и тёмная темы GitHub, Mica.
- Якоря заголовков как на GitHub, переходы по относительным `.md` с историей «назад / вперёд».
- Живая перезагрузка при изменении файла. Документ 3,7 МБ показывает первый экран за те же ~65 мс.
- Окно открывается там, где его закрыли.

Клавиши, настройки и устройство кода описаны в [app/README.md](app/README.md), ограничения текущей версии и план до 1.0 — в [docs/PLAN.md](docs/PLAN.md), история изменений — в [CHANGELOG.md](CHANGELOG.md).

## Сборка

Нужны Windows 10/11 x64 и Visual Studio 2022 или новее: любая редакция или Build Tools с workload «Desktop development with C++». CMake и Ninja входят в состав VS.

```powershell
pwsh -File app/build.ps1    # → app/build/Release/FastMD.exe
```

Готовых сборок пока нет: установщик и подпись в плане (этап 5).

Чтобы `.md` открывались двойным кликом, выберите пункт контекстного меню «Открывать .md в FastMD…» или выполните `FastMD.exe --register`. Регистрация идёт в HKCU, права администратора не нужны.
