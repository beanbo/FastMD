# История изменений FastMD

Формат: [версия] — дата — что изменилось. Планы — в [docs/PLAN.md](docs/PLAN.md).

## [Не выпущено]

- Исходники открыты на GitHub под лицензией GPL-3.0. В корне появились README.md и LICENSE.
- Сборка находит любую редакцию Visual Studio 2022+ или Build Tools с C++ через vswhere, а не только Community по жёсткому пути.
- Замеры: пути к сторонним программам в `proto.json` задаются через переменные окружения (`%LOCALAPPDATA%`).

## [0.1.1] — 19.09.2026

- **Окно открывается там, где было закрыто.** Запоминаются положение, размер и развёрнутость. Окно сразу создаётся в нужном месте, без лишних перемещений, на скорость старта это не влияет. Несколько документов, открытых подряд, раскладываются каскадом. Если монитор отключили, окно откроется на основном.
- Положение сохраняется и при выходе из системы или перезагрузке.
- Разработка: dev-сборка (`app/build`) отделена от рабочей копии (`app/out/Release`, `publish.ps1`). Открытые документы больше не мешают пересборке, а замеры скорости остаются честными.
- Документы: подробный план развития `docs/PLAN.md` заменил `ROADMAP.md`.

## [0.1.0] — 19.09.2026

Первая версия, около 64 мс до первого экрана.

- **Движок:** C++20 + Win32 + DirectWrite (первый кадр на CPU, без GPU) + md4c; сначала верстается только первый экран, большие файлы разбираются начиная с префикса.
- **Рендер:**
  - CommonMark + GFM, GitHub Alerts, YAML front matter;
  - подсветка 17 языков, цветные эмодзи, CJK;
  - локальные картинки, вынос широких блоков за колонку.
- **Чтение:**
  - выделение, копирование, кнопка копирования кода;
  - поиск Ctrl+F;
  - зум, темы (системная, светлая, тёмная), Mica.
- **Навигация:** якоря GitHub, относительные .md с историей, внешние ссылки по белому списку.
- **Окружение:**
  - Ctrl+O, drag-and-drop, живая перезагрузка;
  - «Открыть в редакторе», «Показать в папке»;
  - ассоциация .md в HKCU.
