# FastMD — дорожная карта

**Главная цель — скорость.** Каждая функция добавляется так, чтобы не попасть на критический путь первого кадра.

- Правило регрессии: `t_content(FastMD) − t_content(baseline-win32)` ≤ 0 мс на medium и ≤ +15 мс на large, в одном чередующемся прогоне `bench.py`.
- Приоритеты взяты из исследования: [REPORT.md](../REPORT.md) §6–9, [research/06](../research/06-product-ux-landscape.md) §5 и §10.

## v0.1 — готово (19.09.2026)

- **Основа.** Продуктовая сборка на базе победившего прототипа: CPU-первый кадр, сначала только первый экран, фоновые замеры высот, префиксный разбор больших файлов. ~64 мс на medium.
- **Оформление.**
  - типографика 16/26, Segoe UI Variable Display, текстовая колонка 680 DIP, вынос широких блоков до 960 DIP;
  - темы GitHub light/dark (по системе или вручную), тёмный заголовок, Mica, без белой вспышки;
  - GitHub Alerts, YAML front matter, цветные эмодзи, CJK.
- **Работа с текстом.**
  - выделение (перетаскивание, двойной и тройной клик, Shift+клик), Ctrl+A, копирование (ячейки таблиц через табуляцию), кнопка копирования блока кода;
  - поиск Ctrl+F с подсветкой и счётчиком, F3 / Shift+F3.
- **Навигация.** Ссылки: якоря GitHub, относительные .md с историей «Назад/Вперёд», внешние по белому списку схем, прочие — после подтверждения.
- **Окружение.**
  - зум, контекстное меню, Ctrl+O, drag-and-drop, живая перезагрузка при изменении файла, «Открыть в редакторе», «Показать в папке»;
  - регистрация ассоциации .md в HKCU (`--register`), недавние документы.
- **Тесты.** Регрессия скорости в харнессе (`bench/protos/fastmd-app`) и UI-смоук (`app/tests/ui_smoke.py`).

## v0.2 — «README с GitHub выглядит как на GitHub»

1. **Горизонтальная прокрутка** широких блоков кода и таблиц: Shift+колесо, свой ползунок у блока.
2. **Оглавление:** боковая панель или всплывающее окно по заголовкам, Ctrl+Shift+O, подсветка текущего раздела.
3. **HTML-подмножество** (06 §4.3) — мини-DOM внутри движка:
   - `<img>` с width/height/align;
   - `<p align>` / `<div align>`, `<br>`, `<details>/<summary>`;
   - `<picture>/<source media=prefers-color-scheme>`, `<sub>/<sup>/<kbd>`, простые `<table>`.
4. **Удалённые картинки:** WinHTTP асинхронно, дисковый кэш, место резервируется по width/height, настройка приватности «всегда / спрашивать / никогда».
5. **SVG с текстом** (бейджи shields.io) через lunasvg.
6. **Сноски и alerts через md4c master.** Закрепить коммит в своём форке и проверить UTF-16-сборку и регрессию автоссылок.
7. **Подсветка через Lexilla** (лексеры Scintilla): синхронно, 0,1–0,3 мс на инициализацию.
8. **Emoji-шорткоды** `:smile:` по таблице gemoji.
9. **Копирование как HTML или Markdown:** карта исходника md4c, указатель минус начало исходника.
10. **Строка поиска:** кнопки ↑ ↓ ✕, учёт регистра; IME для CJK через окно ввода в отдельном потоке.
11. **Память о документе:** позиция чтения по файлу, положение окна.

## v0.3 — «продукт»

1. **Доступность:** UI Automation `TextPattern`, проверка в Экранном дикторе.
2. **Печать / экспорт в PDF.**
3. **Формулы и диаграммы в фоне:** RaTeX для формул (≈0,07 мс на формулу), mmdr для Mermaid. Запасной путь — скрытый (cloaked) WebView2 → SVG-кэш, только для документов, где это есть.
4. **Панель просмотра Проводника** (`IPreviewHandler`, in-proc DLL): PowerToys тратит на это 0,6–1,4 с.
5. **Поставка:** установщик, подпись кода (против SmartScreen), автообновление.
6. **Отдельно по замеру на слабом ноутбуке и 4K:** второй бэкенд прокрутки (D2D WARP/HW) и резидентный режим с DelegateExecute (≈86 → 35–40 мс от двойного клика).

## Открытые вопросы

- Кроссплатформенность: сейчас зафиксировано «только Windows». Движок на DirectWrite не переносится.
- Показ окна без активации вместо `ImmDisableIME` — не мерилось из Explorer.
- Холодный старт после перезагрузки не мерился: нужна админ-сессия для очистки standby list.
