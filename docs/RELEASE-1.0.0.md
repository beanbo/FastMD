# FastMD 1.0.0 — примечания к выпуску

*Текст выпуска, опубликованного 21.09.2026: <https://github.com/beanbo/FastMD/releases/tag/v1.0.0>. Команды выпуска — в конце файла; следующий выпуск — [1.1.0](RELEASE-1.1.0.md).*

---

**Молниеносный просмотрщик Markdown для Windows.** От запуска до отрисованного документа — **66 мс**; пустое окно
Win32 без настройки открывается за 79 мс на той же машине и в том же прогоне.

Это первый выпуск, в котором сделано всё, что планировалось к 1.0: этапы 2–6 плана.

## Что нового по сравнению с 0.2.0

**README с GitHub выглядит как на GitHub.** Подмножество HTML (выравнивание, `<details>`, `<picture>`, таблицы,
`<kbd>`, картинки внутри строки), SVG и бейджи, картинки из сети с дисковым кэшем, сноски, эмодзи-шорткоды, front
matter таблицей, подсветка 55 языков.

**Формулы и диаграммы.** `$E = mc^2$` и `$$…$$` набираются по-настоящему — дроби, корни, суммы с пределами, матрицы,
системы (RaTeX, совместим с KaTeX). Блок ```` ```mermaid ```` рисуется диаграммой: 29 видов схем, без браузера.
Обе библиотеки подгружаются только у документа, где они нужны.

**Работа с текстом.** Выделение с клавиатуры, копирование с оформлением (HTML + RTF) и как Markdown-исходник
(Ctrl+Shift+C), перетаскивание текста, ссылок и картинок в другие приложения, печать и экспорт в PDF (Ctrl+P,
Ctrl+Shift+P) — текстом, а не картинкой: в PDF можно искать и выделять.

**В Проводнике.** Панель просмотра .md на том же движке — **10–19 мс** до нарисованного документа (у PowerToys
Markdown Preview — 0,6–1,4 с) — и эскизы-страницы вместо значка файла.

**Установка и обновления.** Установщик для одного пользователя, без прав администратора: `%LOCALAPPDATA%\Programs\FastMD`,
ярлык в «Пуске», запись в «Приложения». Проверка обновлений раз в сутки, загрузка — только по согласию и со сверкой
SHA-256; всё это выключается в настройках.

**Доступность.** Диктор и NVDA читают документ, ходят по словам, строкам, абзацам и заголовкам. Высококонтрастная
тема Windows поддержана.

**Надёжность.** Сбой оставляет minidump в `%LOCALAPPDATA%\FastMD\crashes` (никуда не отправляется). Разборщик
прогоняется фаззером с AddressSanitizer — одно зависание на битом HTML нашлось и исправлено ещё до выпуска.

## Что не вошло

- **Подписи кода нет** — нужен сертификат. При первом запуске SmartScreen предупредит: «Подробнее» → «Выполнить в
  любом случае».
- **Прогона на слабом ноутбуке нет** — нужен другой компьютер. На этой машине проверено, что старт не упирается в
  число ядер (65 мс на четырёх ядрах против 64 на шестнадцати).
- `sequenceDiagram` с активацией (`A->>+B`) пока показывается исходником — ограничение рендерера диаграмм.

## Установка

| Способ | Что делать |
|---|---|
| Установщик | скачайте `FastMD-Setup.exe` и запустите. Права администратора не нужны |
| Без установки | распакуйте `FastMD-1.0.0-win-x64.zip` куда угодно и запустите `FastMD.exe` |

Проверить загруженное: рядом лежат `.sha256`.

Полный список изменений — в [CHANGELOG.md](../CHANGELOG.md), план и что осталось — в [docs/PLAN.md](PLAN.md).

## Как выпустить (для владельца)

```powershell
pwsh -File app\package.ps1                 # zip + FastMD-Setup.exe + оба .sha256 в app\out\dist
git tag -a v1.0.0 -m "FastMD 1.0.0"
git push origin v1.0.0
gh release create v1.0.0 `
    app\out\dist\FastMD-1.0.0-win-x64.zip app\out\dist\FastMD-1.0.0-win-x64.zip.sha256 `
    app\out\dist\FastMD-Setup.exe app\out\dist\FastMD-Setup.exe.sha256 `
    --title "FastMD 1.0.0" --notes-file docs\RELEASE-1.0.0.md
```

После выпуска — манифест winget: `packaging/winget/README.md`.
